# Security policy

## Supported versions

Security fixes target the latest release and the `master` branch. Older releases
are not maintained separately. Install the latest version from
[GitHub Releases](https://github.com/kevinjhampier/ViewImage/releases/latest).

## Report a vulnerability privately

Use the repository's [private vulnerability reporting form](https://github.com/kevinjhampier/ViewImage/security/advisories/new).
Do not publish exploitable details in a public issue before the maintainer has
had an opportunity to review them. Include the affected version, steps to
reproduce, impact, and a minimal proof of concept. Do not include unrelated
personal data or live credentials.

If the private reporting form is unavailable, open an issue asking the maintainer
to enable a private reporting channel, without posting vulnerability details.
There is no guaranteed response time or bug bounty program.

## Scope

Reports concerning this fork's extension code, permissions, release packages,
and website are welcome. Vulnerabilities in Google Images, Firefox, Chromium,
or GitHub should be reported through those vendors' security channels.
